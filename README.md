# JavaScript

A step-by-step, beginner-to-expert JavaScript learning path. Each topic below is a
self-contained document with explanations, runnable code examples, best practices,
common pitfalls, and an interview-preparation section.

## How to use this folder
1. Go through the topics in order — later topics (closures, prototypes, async) build on
   earlier ones (variables, functions, objects).
2. Try every code example yourself in a browser console or Node.js REPL.
3. Use the **Interview Questions** section at the end of each file for quick revision
   before interviews.
